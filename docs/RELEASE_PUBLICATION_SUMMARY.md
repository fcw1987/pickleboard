# Public release snapshot

This snapshot is prepared from the approved Pickleball Park runtime and the current public main baseline. It carries the runtime source, maintainer contracts, and a small set of reviewed app-only stills.

The public documentation intentionally excludes recordings, raw test logs, browser metadata, local checkout paths, historical evidence dumps, and superseded review artifacts. Those remain local development material. Retained links resolve within this snapshot.

The still evidence covers the editable board, guided lesson, 3D replay, menu, and help states. It does not claim physical-device, native-Safari, frame-accurate video, or universal performance coverage.

See [rebrand verification](REBRAND_VERIFICATION.md), [coaching verification](PARK_COACHING_VERIFICATION.md), and [release notes](RELEASE_NOTES.md) for the public scope and maintainer-facing limits.
